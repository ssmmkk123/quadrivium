# Documentation overhaul roadmap and acceptance criteria

## Execution phases

- **Phase A**: asset architecture, standards, and audit baseline.
- **Phase B**: core pages (`index`, `getting-started`, `design`, `limitations`, `examples`, `faq`).
- **Phase C**: all 13 guide pages with standardized visual evidence sections.
- **Phase D**: navigation, cross-link consistency, and reliability checks.
- **Phase E**: final editorial consistency pass.

## Acceptance criteria

- Every guide page contains meaningful visual evidence linked to decision-making or numerical behavior.
- Core docs clearly explain entry points, method choice, and result interpretation using figures.
- Docs quality checks catch broken image links, missing alt text, and orphaned assets.
- Generated docs checks and doctests remain passing.
