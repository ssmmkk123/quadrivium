# Support

Start with the [documentation](https://ssmmkk123.github.io/quadrivium/): the
[getting-started guide](https://ssmmkk123.github.io/quadrivium/getting-started/)
covers the conventions every routine shares, each
[subpackage guide](https://ssmmkk123.github.io/quadrivium/guides/linalg/) opens
with a table mapping a situation to a method, and the
[API reference](https://ssmmkk123.github.io/quadrivium/api/) lists every
signature. The [FAQ](https://ssmmkk123.github.io/quadrivium/faq/) and
[known limitations](https://ssmmkk123.github.io/quadrivium/limitations/) answer
most of what is left; the scripts in `examples/` are runnable tours.

For a reproducible bug, open a bug report and include your Python, NumPy, and
Quadrivium versions along with a minimal example. For usage questions, use
GitHub Discussions if it is enabled; otherwise, open a regular issue and make
it clear that you are asking a question.

Security and conduct concerns should follow the private reporting instructions
in `SECURITY.md` and `CODE_OF_CONDUCT.md`.
